# book-agent

Книжный агент — личный ассистент для чтения книг и статей.

## Установка

Нужен Node 24. Один раз в корне репо:

```
npm ci
```

## Импорт EPUB

Из корня репо:

```
npm run import -- книга.epub out/книга
```

Получится папка `out/книга/`:

- `book.md` — шапка и оглавление. В шапке по строке: Автор, Язык, Переводчик, Издатель, Год, ISBN, Глав, Частей, Сносок (число сносок во всех частях; 0 — если их нет); данные издания берутся из самого файла книги, чего в нём нет — «не указан». Переводчик — тот, у кого в файле роль переводчика (в «Автор» он не попадает); год — год издания из даты в файле (явно ненастоящий, вроде 0101, не пишется); ISBN — только настоящие, с верной контрольной цифрой, печатный и электронный через запятую. В оглавлении — номер части, заголовок главы или подглавы, имя файла, число слов. По номеру просите в сессии чтения: «дай часть 003-02».
- `parts/` — текст книги в markdown, по частям в порядке чтения:
  - `001.md` — глава без подглав целиком;
  - `002-00.md`, `002-01.md`, `002-02.md`, … — глава с подглавами: `-00` — текст до первой подглавы (если он есть), дальше — подглава за подглавой.

В тексте частей заголовок главы — `#`, подглавы — `##`, мелкие заголовки — `###`; курсив и жирный сохранены, картинок и оформления нет. Внутри абзаца, пункта списка и цитаты пустых строк нет: строфы и переносы строк в одном абзаце исходника — одним переносом, чтобы абзац исходника был одним абзацем в счёте (раздел «Ссылки на место»).

Обложка и другие страницы без текста пропускаются.

### Сноски

Сноска, текст которой лежит в той же главе (EPUB 3 `aside`, блок примечаний в конце главы, примечание после абзаца), в части выглядит как сноска markdown: в абзаце — метка `слово[^1]`, а в самом конце файла части — определения одним блоком:

```
…последний абзац.

[^1]: Текст сноски.
[^2]: Другая сноска.
```

- Номера меток — по первому появлению в файле части сверху вниз, с 1 (заголовки тоже считаются). Несколько ссылок на одно примечание в одной части — одна метка; если глава разбита на подглавы, в каждой части свои метки и свои определения.
- Из текста главы примечание уходит; раздел «Примечания» целиком (заголовок, `---`, список) — тоже, если в нём больше ничего нет. Примечание, на которое не ведёт ни одна сноска, остаётся обычным текстом там, где стоит.
- Текст сноски — одна строка: курсив и жирный сохранены, несколько блоков и переносы строк — через пробел; обратная ссылка («↩») и ведущий знак (`1`, `[1]`, `1.`, `*`) убраны.
- Сноской считается ссылка на примечание в этом же документе с пометкой сноски (`epub:type="noteref"`, `role="doc-noteref"`) или с номером (`1`, `[1]`, `*`, `†`) в верхнем индексе. Ссылка на раздел с заголовками и ссылка на другой файл книги — не сноска, текст ссылки остаётся в тексте как был.
- Сноска в заголовке остаётся меткой в файле части (`# Глава 1[^1]`), а в `book.md` заголовок — без метки.
- Сноски, чей текст лежит в другом файле книги (отдельный файл примечаний), пока не разбираются: остаются как раньше — номер слитно со словом, файл примечаний — отдельной частью.
- Сноски не сдвигают номера абзацев `¶` (раздел «Ссылки на место»).

Служебные страницы издания — обложка, титульный лист, выходные данные (©, ISBN, УДК/ББК), оглавление самой книги — тоже не становятся частями, чтобы не сбивать нумерацию глав. Их видно по разметке файла книги, а если её нет — по признакам: короткая страница с выходными данными (аннотация на той же странице пропускается вместе с ними), страница из одних ссылок на главы, короткая страница с названием книги. В сомнительных случаях страница остаётся: «Часть первая», посвящение, эпиграф, предисловие, примечания не пропускаются. Что пропущено и почему, видно в `book.md` — в разделе «Пропущено» под оглавлением: файл в архиве, первые слова страницы, причина. Если импорт ошибся, возьмите всё без пропусков ключом `--all` (в любом месте после `--`):

```
npm run import -- книга.epub out/книга --all
```

Если служебными оказались все страницы, команда так и пишет и ничего не создаёт. Если файл не EPUB или архив повреждён, команда пишет, в чём дело, и ничего не создаёт. Папка назначения должна быть новой или пустой: в папку с файлами импорт не пишет, чтобы ничего не перезаписать.

Раскладка `book.md` + `parts/` — черновая; окончательную раскладку книги в библиотеке утвердит владелец.

## Импорт PDF

PDF с текстовым слоем (не скан) — та же команда:

```
npm run import -- книга.pdf out/книга
```

Формат определяется по содержимому файла, а не по расширению. Получится та же папка, что из EPUB: `book.md` и `parts/`.

- Главы и подглавы — по закладкам PDF (оглавление сбоку в программе просмотра): закладка верхнего уровня — глава, вложенная в неё — подглава (`003-01`, `003-02`, …, даже если она одна; текст до первой подглавы — `003-00`). Закладки глубже не делят текст. Текст до первой закладки (титул, аннотация) — отдельной главой «До первой закладки».
- Заголовок главы — `#` из закладки, подглавы — `##`; напечатанный на странице такой же заголовок в тексте не повторяется.
- PDF без закладок — главы и подглавы по заголовкам, набранным крупнее основного текста; команда предупреждает: «главы размечены по крупному шрифту, проверьте оглавление в book.md». Правило:
  - размер строки — тот, которым набрано больше всего её букв (поднятая буквица строку крупной не делает); размеры, отличающиеся меньше чем на 5 %, считаются одним;
  - основной размер — тот, которым набрано больше всего букв книги (без колонтитулов и номеров страниц);
  - строка заголовка — не мельче 1,2 × основного, не длиннее 120 знаков, не из одной буквы (кроме римских `I`, `V`, `X`) и не строка оглавления с номером страницы после отточия; заголовок — до трёх таких строк подряд одним размером на одной странице, больше трёх — текст крупным шрифтом;
  - строки заголовка склеиваются через пробел, после номера — через «. » (`Chapter 1` + `Beginning` → «Chapter 1. Beginning»); номер отдельной строкой склеивается со следующим заголовком: «1» + «Начало» → «1. Начало»;
  - заголовок с тем же текстом, что прошлый того же размера (крупный колонтитул главы), идёт текстом;
  - уровень — размер, которым набраны хотя бы два разных заголовка на разных страницах: самый крупный уровень — главы (`#`), следующий — подглавы (`##`), части — как у закладок. Остальные заголовки (название книги и автор на титуле) текст не делят и стоят в нём строкой `### …`. Подглава до первой главы — глава сама по себе; текст до первого заголовка — отдельной главой «До первого заголовка»;
  - уровней нет — книга одной главой «Текст», команда предупреждает, что главы не размечены.
- Принятые ошибки разметки по шрифту: оглавление книги, набранное крупно, но без номеров страниц, может дать лишние главы; заголовок, перешедший на следующую страницу, — два заголовка; заголовки основным размером, выделенные только жирным или капителью, не находятся; длинный заголовок, перенесённый после числа (`Записки 1812` + `года`), склеится через «. ».
- Абзацы собираются из строк страницы: новый абзац — после увеличенного промежутка между строками или по отступу первой строки; абзац, который переходит на следующую страницу, остаётся одним абзацем.
- Колонтитулы убираются: строка у верхнего или нижнего края страницы (в полосе 8 % её высоты), которая без учёта цифр повторяется у того же края на половине страниц книги и больше — или на половине чётных, или нечётных (слева автор, справа название). В книге меньше 4 страниц колонтитулы не ищутся.
- Номера страниц убираются: число у края страницы (или «— 12 —», «12 / 300»), если на соседней странице номер идёт подряд. Число у края, которое ряд не продолжает (год, номер сноски), остаётся.
- Переносы склеиваются: строка кончается дефисом, следующая начинается со строчной буквы — слово собирается без дефиса (`пере-` + `носах` → `переносах`); иначе дефис остаётся. Мягкие переносы убираются. Принятая ошибка: составное слово, разорванное ровно на своём дефисе (`какой-` + `нибудь`, `well-` + `known`), склеится без дефиса.
- В `book.md` название и автор — из сведений самого PDF; переводчик, издатель, год, ISBN — «не указан». Раздела «Пропущено» нет, ключ `--all` для PDF ничего не меняет.

Что пока не поддерживается:

- сканы (PDF без текстового слоя) — команда так и пишет и ничего не создаёт;
- сноски остаются в тексте;
- перенос мягким дефисом (U+00AD) в конце строки библиотека чтения PDF не отдаёт — такое слово остаётся разорванным пробелом: `пере носах`;
- PDF с паролем — команда пишет, что нужен пароль, и ничего не создаёт (защищённый без пароля на открытие читается как обычный).

## Порция кусок за куском

Большую книгу можно вводить порциями: кусок текста (файл или вставка) становится следующей главой уже импортированной книги (решение Б-09 в `docs/решения.md`). Из корня репо:

```
npm run import -- --append кусок.txt out/книга
npm run import -- --append - out/книга
```

`-` — текст из вставки: вставьте его в терминал и нажмите Ctrl-D в начале пустой строки. Ключи — в любом месте после `--`: `--title "…"` — свой заголовок части, `--again` — дописать повтор (ниже). Значение ключа — отдельным аргументом (`--title "Глава 5"`, а не `--title=Глава 5`).

- **Кусок** — простой текст или markdown в UTF-8 (BOM и переводы строк Windows не мешают). EPUB и PDF порцией не дописываются: импортируйте файл целиком в отдельную папку, а кусок возьмите из её части.
- **Заголовок части** — первая непустая строка куска, если она начинается с `# ` (`##` и глубже — нет); эта строка уходит из текста. `--title "…"` важнее неё. Нет ни того, ни другого — «Без названия». В оглавлении заголовок — без меток сносок `[^N]`.
- **Абзацы.** Есть в куске пустые строки (строка из пробелов — тоже пустая) — абзацы делятся только по ним, перенос строки внутри абзаца остаётся, несколько пустых строк подряд — одна. Пустых строк нет — каждая строка становится абзацем; пустая строка сразу после заголовка, в начале и в конце куска не в счёт. В обоих случаях блок кода в ```` ``` ```` — один блок, строки заголовков (`## Раздел`) и разделители (`---`, `***`, `* * *`) — отдельным блоком, пробелы в конце строк убираются. Строки `[^N]: …` подряд в конце куска без пустых строк — определения сносок одним блоком (они не абзацы и прибавляются к «Сносок» в `book.md`).
- **Номер части** — следующий после последней главы в оглавлении `book.md`: после `003` или `003-00…003-02` — `004.md`. Часть — всегда целиком, без подглав. Готовые части и номера их абзацев не меняются; в `book.md` добавляется строка оглавления (перед «Пропущено»), «Глав» и «Частей» — плюс один, остальное — байт в байт.
- **Повтор.** Если текст куска совпадает с текстом одной из прежних частей (без строки заголовка), команда пишет «такой кусок уже есть: часть NNN» и ничего не дописывает. Если повтор нужен, — ключ `--again`.
- **Новая книга.** Первый кусок может завести книгу в новой или пустой папке — тогда нужно название, автор по желанию:

  ```
  npm run import -- --append кусок.txt out/книга --book-title "Название" --author "Автор"
  ```

  В `book.md` язык и данные издания — «не указан», кусок — `001.md`. С `--book-title` или `--author` в папку готовой книги команда не пишет: «книга уже заведена — не та папка?».

Если что-то не так — папка без `book.md`, оглавление `book.md` не сходится с `parts/`, кусок пуст или не в UTF-8, глав уже 999, — команда пишет, в чём дело, и папка остаётся как была.

## Ссылки на место

Ссылка на место в книге — часть и номер абзаца: `003-02 ¶12` — часть 003-02, двенадцатый абзац; `003 ¶1–40` — абзацы с 1 по 40 части 003. Часть — как в оглавлении: `NNN` или `NNN-MM`.

Как считаются абзацы — по файлу части `parts/NNN[-MM].md`:

- файл делится на блоки по пустой строке (строка из одних пробелов — тоже пустая);
- блок кода от строки ```` ``` ```` до закрывающей ```` ``` ```` — один блок, пустые строки и `#` внутри него ничего не делят;
- не считаются заголовки — блоки, которые начинаются с `#`…`######` и пробела (`#1 в списке` — абзац), и разделители — блок из одного `---`, `***` или `* * *`;
- блок в самом конце файла, где каждая строка начинается с `[^` + цифры + `]: `, — определения сносок (решение Б-07): не абзац, номеров не сдвигает; метка `[^1]` внутри абзаца — часть абзаца;
- остальные блоки — абзацы, по порядку с 1. Список, таблица и цитата — один абзац.

Номера в текст не вписываются: их показывает команда, она и есть мерило. Из корня репо:

```
npm run show -- out/книга 003-02
npm run show -- out/книга 003-02 ¶12
npm run show -- out/книга 003-02 ¶3–5
```

Без номера — вся часть: каждый абзац начинается с номера (`¶1 Текст…`), заголовки, разделители и блок определений сносок — как есть, без номера. С номером — только этот абзац; с диапазоном (тире или дефис) — абзацы диапазона и заголовки с разделителями между ними. Ссылку можно вставить и целиком, как из разбора: `npm run show -- out/книга "003-02 ¶12"` или `003-02¶12`.

Номер без `¶`, часть не того вида, нет такой части, папки книги или абзаца — команда пишет, в чём дело (сколько абзацев в части; на какие части разбита глава, если просили главу целиком), и ничего не показывает.

Правка текста части сдвигает номера, поэтому файлы в `parts/` руками не правятся (решение Б-04 в `docs/решения.md`).
