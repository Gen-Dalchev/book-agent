# CLAUDE.md

**Книжный агент** — личный ассистент для чтения книг и статей, оптимизированный под владельца (`Gen-Dalchev`). Движок — Claude Code на подписке владельца: разбор и вопросы делают навыки и инструкции этого репо, а тексты и разборы лежат markdown-файлами в отдельном закрытом репо `book-library`. Своего приложения с Claude API пока нет; код не должен мешать его завести.

Здесь — код: импорт форматов (сначала EPUB, затем PDF с текстовым слоем) в главы markdown, поиск, навыки. Замысел целиком — карточка проекта в штабе владельца; план — `docs/план.md`, решения — `docs/решения.md`, метод чтения — `docs/чтение.md`.

## Стек и правила

- Node 24, `npm`. Тесты — `npm test`, итог по коду выхода. Стек может смениться: держать логику в обычных модулях, без привязки к фреймворку.
- Языки текстов: сначала русский; английский и другие — без переделки: UTF-8, разбиение на главы — по структуре файла, а не по словам вроде «Глава».
- Репо **публичный**: сюда не кладутся тексты книг, разборы, заметки владельца, ключи. Тестовые файлы — свои маленькие (EPUB, собранный в тесте, пара абзацев своего текста) или общественное достояние.
- Интерфейс и документы — на русском, имена в коде — на английском.

## Для конвейера

Агенты конвейера «Штаб» (`Gen-Dalchev/Shtab_Dalcheva`) работают здесь без человека: берут issue с меткой `готово`, присылают PR, сливает только человек. Правила выше действуют целиком; здесь — только то, что агенту нужно сверх них.

- **Клон:** `npm ci`. Пока нет `package-lock.json` (первая задача) — `npm install`, lock-файл — в том же PR.
- **Проверки перед PR:** `npm test`, `npm run build` (если есть) — итог по коду выхода. Те же гоняет CI на каждый PR («Проверки PR»).
- **Только через `нужно-решение`:** новая зависимость, если задача её не называет; правка `.github/`, этого файла и `docs/` (кроме переноса блока «Решение» — ниже); раскладка файлов книги в `book-library` — её утверждает владелец
- **Блок «Решение»** в тексте issue (Штаб, Ш-37, Ш-44) — решение владельца, принятое до задачи: перенести его в `docs/решения.md` (нет файла — завести), в том же PR, что и код
- **Данные:** `book-library` и любые тексты книг — не открывать, не клонировать, не скачивать; личные данные в репо не кладутся
- **Отчёт** — в описании PR, по шаблону Штаба; журналы и планы проекта агент не правит
- **После слияния** — выкатки нет: владелец забирает `main` и запускает команды из README у себя или в сессии чтения
