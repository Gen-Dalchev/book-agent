# Приём книги — шаг 0

Владелец только загружает файл. Распаковку, импорт, проверку оглавления и паспорт делает сессия; команд владелец не вводит. Его слово нужно трижды: огрехи оглавления, slug, паспорт.

Сначала прочитай `.claude/reading/rules.md` (от корня `book-agent`) и `docs/чтение.md` целиком.

## 1. Подготовка

1. Найди оба клона (`rules.md`, «Где что»). В `book-agent` — `npm ci`, если нет `node_modules`. В `book-library` — `git pull`.
2. В корне `book-library` нет `CLAUDE.md` — положи шаблоны из `templates/` этого навыка: `library-CLAUDE.md` → `CLAUDE.md`, `library-gitignore` → `.gitignore`. Коммит «Правила библиотеки из шаблона book-agent», push в `main`. Есть, но в его строке «Шаблон:» дата старше, чем в шаблоне, — покажи владельцу разницу и обнови только с его слова.

## 2. Файл книги

1. Файл — самый новый в `/root/.claude/uploads/<id сессии>/` (`ls -t`). Несколько новых, и неясно, какой книга, — спроси.
2. По расширению и первым байтам:
   - `.epub`, `.pdf`, `.fb2` — как есть;
   - `.zip`, `.7z`, `.rar` (в том числе `.fb2.zip`) — `npm run unpack -- <архив> <scratchpad>/unpack-<N>` в новую пустую папку. Файл книги в выводе помечен «книга»; их несколько — спроси владельца. EPUB команда не распаковывает — его импортируют как есть.
3. Ошибка «не похож на PDF или EPUB» у `.fb2` — импорт FB2 ещё не слит (#45): скажи владельцу и остановись.

## 3. Пробный импорт и проверка оглавления

1. `npm run import -- <файл> <scratchpad>/import-<N>` — в scratchpad, не в библиотеку. Сохрани вывод: предупреждения нужны для журнала.
2. Проверь `book.md` — **только структуру**, текст частей не открывай (изоляция):
   - глав и частей — сколько, слов всего (сумма по оглавлению);
   - одна глава на книгу больше ~5 тыс. слов — главы не размечены (EPUB одним файлом до #44, PDF без закладок и крупных заголовков);
   - часть больше ~15 тыс. слов без подглав — вероятно, главы внутри не найдены;
   - части меньше ~50 слов подряд, заголовки вида «Содержание», «Аннотация», «©», «До первой закладки», «Текст», «Без названия» — служебные страницы или пустые заголовки;
   - «Пропущено»: нет ли среди пропущенного главы книги (по первым словам и причине);
   - предупреждения импорта; данные издания «не указан».
3. Начало книги можно посмотреть: первая часть — всё равно первая порция (`npm run show -- <папка> 001` или первая по оглавлению). Дальше — нельзя; сомнение по поздней части — спроси владельца, пусть посмотрит сам.
4. Доложи коротко: глав, частей, слов, что не так. Огрех — варианты владельцу:
   - принять как есть (запись в журнал при заведении);
   - другой ключ импорта (`--all`, если пропущено лишнее);
   - подождать задачу импорта: issue в `book-agent` — только с его слова и только структурой (`rules.md`, «Публичное и закрытое»).

## 4. Импорт в библиотеку

1. **Slug** — транслит названия латиницей, строчные, слова через `-`, без автора (автор — только если такая папка уже есть). Папки `books/<slug>/` быть не должно. Предложи — владелец подтверждает.
2. `npm run import -- <файл> <book-library>/books/<slug>` — с теми же ключами, что и пробный. Глав и частей — столько же, сколько в пробном.
3. Коммит `<slug>: импорт` (`book.md`, `parts/`), push.
4. Книга теперь заморожена (Б-04): повторный импорт в эту папку не делается; новая версия книги — только словом владельца и записью в журнал, какие ссылки сдвинулись.

## 5. Исходный файл

В git он не идёт; хранит его владелец в своём резерве (Б-01, Б-16). Запиши в паспорт имя, размер, `sha256sum` — по ним потом опознаётся издание для повторного импорта (Б-04). Из архива — данные и архива, и файла книги.

## 6. Паспорт, журнал, справочники

1. Заполни `passport.md` по `templates/passport.md`:
   - **издание** — из `book.md`; чего нет — спроси (переводчик, издатель, год; книга не в переводе — «оригинал»);
   - **профиль** по `docs/чтение.md`: художественная книга — проза; другие — по таблице профилей, смешанная — справочники двух профилей;
   - **изоляция**: проза — строгий; философия — термины; нон-фикшн — проверка;
   - **режим** — живой (автономный — отдельный вариант навыка, его ещё нет);
   - **план порций** — по числу слов в оглавлении: ориентир 3–7 тыс. слов (≈ 10–25 страниц) или законченный смысловой узел; мелкие главы объединяй, порция не рвёт подглаву. Часть длиннее ~8 тыс. слов делится диапазонами `¶` — число абзацев части без показа текста даёт `npm run show -- <папка> "<часть> ¶99999"` (ошибка называет, сколько абзацев); точную границу уточни, когда дойдёшь до этой части.
2. Покажи паспорт владельцу, поправь по его слову.
3. `journal.md` по `templates/journal.md`: первая запись — шаг 0: файл, ключи импорта, предупреждения, огрехи и что с ними решили.
4. `refs/` — файлы ядра и профиля из паспорта, в каждом только заголовок `# …` и строка «что здесь» из `docs/чтение.md`. Записи появятся с первой порцией.
5. Коммит `<slug>: паспорт, журнал, справочники`, push.

## 7. Дальше

Спроси, начинаем ли порцию 1, — и переходи к навыку `reading`. Владелец будет читать сам: скажи, какие части (по заголовкам оглавления) входят в порцию 1.
