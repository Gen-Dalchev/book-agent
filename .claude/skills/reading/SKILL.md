# Чтение — разбор порции

Шаги 1–5 цикла из `docs/чтение.md`. Шаг 0 (приём книги) — навык `book-intake`, шаг 6 (ретро) — `reading-retro`.

Сначала прочитай `.claude/reading/rules.md` (от корня `book-agent`) и `docs/чтение.md` целиком, если в этой сессии ещё не читал.

## 0. Где мы

1. `git pull` в `book-library`. Книга — та, что назвал владелец; не назвал — папка из `books/` с `passport.md`, а если их несколько — спроси.
2. Прочитай `passport.md` (издание, уровень изоляции, режим, план, «Сейчас»), конец `journal.md` (последние записи и правила об ошибках) и `me/предпочтения.md`, если он есть, — правила из обоих соблюдай.
3. Режим «автономный» — этот навык не для него (вариант навыка появится позже, п. 6 плана): скажи владельцу.
4. Есть разбор со `Статус: открыт` — продолжай его с того шага, где остановились. Нет — следующая порция по плану.
5. Книга идёт кусками (Б-09), и владелец прислал следующий кусок (файл или текст в сообщении) — допиши его: `npm run import -- --append "<файл>" "<папка книги>"` (текст из сообщения — сначала в файл в scratchpad), добавь порцию в план паспорта, коммит `<slug>: кусок NNN`, push.
6. Справочники: `refs/` грузи нужное — небольшие файлы целиком; большие — поиском записей по именам (`### Имя`), которые встречаются в порции. Старые разборы — поиском по ссылке, не целиком.

## 1. Порция

1. Сними расход на начало: `get_session` → `external_metadata.context_usage.used_tokens` — для шапки разбора.
2. Прочитай текст порции сам: `npm run show -- <папка книги> <часть>` для каждой части (или диапазон `¶`). Только части порции (`rules.md`, «Изоляция»).
3. **Порция кончается внутри части** (план — диапазоном `¶`) — уточни границу, не читая дальше конца порции по плану: шов — последний заголовок или разделитель (`---`, `* * *`) внутри показанного диапазона, ближе к его концу; шва нет — граница по плану. Сдвинул границу — поправь план в паспорте (следующая порция начинается со следующего `¶`).
4. Назови владельцу порцию: номер, части и заголовки из оглавления. Кончается внутри части — назови конец словами, чтобы он нашёл его в своей читалке: первые слова последнего абзаца порции (это текст текущей порции, изоляция не страдает). Владелец читает сам — уточни, прочитал ли он; разбор — после его чтения.
5. Заведи `notes/NN-<первая часть>.md` по `templates/note.md` (NN — номер порции двумя цифрами, `¶` в имени нет): `Статус: открыт`, в шапке — контекст на начало.

## 2. Саммари и изменения для справочников — субагент

Прототип моделей (п. 5 плана): шаги 1–2 делает субагент на средней модели, основная сессия проверяет.

1. Запусти Agent: `subagent_type: "general-purpose"`, `model: "sonnet"`. В промпте — всё, что ему нужно, он не видит этот разговор:
   - номер порции N (для строк `Δ п.N`), путь к книге и **точный список частей**, которые можно открыть (`npm run show -- <папка> <часть>`); остальные части не открывать, по `parts/` не искать;
   - пути к `refs/` и формат записи из `docs/чтение.md` («Запись»), к `rules.md` — пометки и голоса;
   - задание: (1) саммари — костяк событий или хода мысли порции, у каждого пункта ссылка `[текст NNN ¶N]`; (2) изменения для справочников — `+` новые записи и `Δ п.N` изменения, по файлам профиля, в форме записи, с пометкой и голосом `ИИ`;
   - запрет: знание о книге из обучения, забегание вперёд, правка файлов — он только возвращает текст.
2. Проверь результат сам (сильная модель):
   - каждую ссылку — по тексту порции с номерами `¶`, который ты уже прочитал (сомнительные и на прошлые порции — `npm run show`): абзац тот;
   - нет ли утверждений без пометки, пересказа не из порции, знания о том, что дальше;
   - не пропущено ли важное в порции; изменения справочников — не дубли существующих записей.
   Исправь и запиши в шапку разбора, что поправил (число ссылок и пунктов) — это замер качества прототипа.
3. Результат плохой (много неверных ссылок, пересказ мимо текста) — сделай шаги 1–2 сам и запиши в журнал ошибкой процесса.
4. Токены субагента из его результата запиши в шапку разбора сразу — для «Замеров» на ретро (сессия может оборваться до ретро).

## 3. Разбор и вопросы — сама сессия

1. **Разбор** — тон, ирония, переклички с прошлыми порциями (по справочникам и ссылкам), заявленные идеи; в нон-фикшне — логика, допущения, границы. Опора на текст, пометки у каждого утверждения. Ответов на будущие вопросы здесь нет.
2. **Вопросы** — столько, сколько в порции важных тем, чтобы все были раскрыты; 2–3 — ориентир, не предел. Вопрос открытый, с местом в тексте, на который он опирается.
3. Запиши шаги 1–4 в разбор, коммит `<slug>: порция N — черновик`, push.
4. Покажи владельцу в чате: саммари, изменения для справочников, разбор, вопросы — целиком, это и есть разговор. Его поправки к саммари и разбору правь в открытом разборе, с голосом `я`.

## 4. Обсуждение

- Спор по существу: соглашайся с точным, возражай с опорой на текст, без придирок к словам и без спора ради спора. Не льсти.
- Мысль владельца — `я`, твоя — `ИИ`, к чему пришли вместе — `спор`.
- На уровне «проверка» (нон-фикшн) факты, даты и выкладки можно проверять поиском по ходу разбора и спора — с пометкой `[источник: …]` и ссылкой.
- Вопрос владельца сверх уровня изоляции (кто такой автор, что было в истории, что дальше в книге) — по `rules.md`, «Изоляция»: знание модели — с пометкой и только если уровень разрешает или владелец прямо просит; вперёд по книге — никогда, даже по просьбе: скажи, что это забегание вперёд.
- Записывай обсуждение в раздел 5 разбора по ходу — суть по вопросам, не стенограмма: мысль, кто её высказал, на что опирается. После заметного куска — коммит и push.
- Новые записи и изменения справочников, родившиеся в споре, — в раздел 2 разбора (с голосом `я` или `спор`); в `refs/` они попадут на ретро.

## 5. Закрытие

Темы исчерпаны или владелец говорит «хватит» / «закрываем» — предложи закрыть порцию и переходи к навыку `reading-retro`. Порция не закрывается без ретро.
